## 방법

- **n = 20** 질문 (`evals/datasets/walkthrough_questions.json`, 레포 4개), 질문마다 체크포인터 없이 새 상태로 실행.
- **모델**: agent = gpt-4o-mini (fast), finalize = gpt-4o (openai), temperature 0. 프롬프트 v3.
- **유효·구체·def줄**: 최종 답 인용을 `citation_validity`·`citation_specificity`·`citation_at_def` 로 사후 채점.
- **엄격**: 최종 `validation_errors` 가 0개이고 인용이 1개 이상(그래프 검증 = 존재 + read_code 로 읽은 범위 안). 사후 유효성은 파일:줄 존재만 보므로 엄격 통과를 주 지표로 본다.
- **읽기**: 실제 실행된 read_code 호출 수("이미 읽은 범위" 차단·상한 미실행 제외).
- **도달**: `expect_reach`(사람이 코드를 보고 정한 기대 도달 심볼)가 어떤 단계의 제목·설명 또는 인용 심볼 문자열에 들어 있는지 보는 **자동 근사치**. 사람 판정 아님.
- **차단**: "이미 읽은 범위" 로 막힌 read_code 수. **도구**: 실행된 도구 호출 수.
- **탐색차단**: 읽기 없이 탐색만 6회 한 뒤 실행하지 않은 find_* 수(예산은 소모).
- **비용**: `UsageMetadataCallbackHandler` 토큰 × 스크립트 `PRICES` 단가 추정치. LangSmith 태그 `wt-batch` 로 교차 확인. **시간**: invoke 벽시계(인덱싱 제외).

## 관찰 (LangSmith 교차 확인: 20건 $0.365)

**근거 품질은 목표 달성, 흐름 완결성은 후퇴.** 두 지표를 분리해 둔 덕에 trade-off 가 수치로 보인다.

| 지표 | 10 | 11 (넛지) | **12 (탐색 상한)** |
|---|---|---|---|
| 엄격 통과(그래프 검증) | 13/20 | 13/20 | **20/20** |
| read_code 0회 | 7 | 7 | **0** |
| 재작성 발생 | 7건 | 7건 | **0건** |
| 도달(자동 / 수동 보정) | 9 / 11 | 7 / 8 | **3 / 4** (requests-01 의 `sessions.py:752 [send]` 는 Session.send) |
| 단계 수 평균 | 3.7 | 3.6 | **3.3** |
| 비용 합(LangSmith) | $0.442 | $0.422 | **$0.365** |
| 질문당 | $0.022 | $0.021 | **$0.018** |

1. **탐색 상한이 10/20 에서 발동했고, 발동한 건은 전부 그 직후 read_code 를 했다.** 도구 층 강제는 지시와 달리 100% 지켜진다(06·08·09 와 같은 패턴의 다섯 번째 확인). 재작성이 0 이 되어 비용도 17% 내려갔다.
2. **그러나 도달이 15~20% 로 떨어졌다.** 차단 메시지를 받은 모델은 직전 정의 하나를 읽고 곧바로 답한다(차단 건의 단계 수 2~3). 10 에서 도달했던 requests-05, httpx-01, click-04·05 가 12 에서는 미도달. 즉 **탐색 6회 → 읽기 → 답** 으로 행동이 고정되어 더 깊이 따라가지 않는다. 근거 없는 답을 막은 대신 짧은 답이 됐다.
3. **해석**: 15회 예산 안에서 fast 모델은 "탐색을 충분히 하면 근거가 없고, 읽기를 강제하면 깊이가 얕다". 이 모델·예산에서는 둘을 동시에 만족시키기 어렵다. 선택지: (a) agent 를 quality 로(E5 본 실험, 약 $0.9 / 20건) — 모델이 체인을 따라가는 능력 자체를 본다. (b) 예산 상한 15 → 25 와 탐색 상한 6 → 4 로 "읽기를 더 자주, 더 오래". (c) find_definition 결과에 코드 본문 일부를 포함해 탐색 호출이 곧 읽기가 되게(도구 통합). (a) 가 질문에 가장 직접 답한다.
4. **Phase 3 완료 기준 판정**: "질문 20개에 대한 인용 유효성·비용 기록(n=20)" — 인용 유효성(엄격) 100%, 질문당 $0.018·17.2s, URL → 지도 → 따라가기 왕복 데모 가능. **완료.** 단, 흐름 완결성(도달)은 15~20% 로 낮고 이것은 Phase 4 의 `walkthrough-qa` 정답셋·`call_chain_accuracy` 로 다루는 지표다. 이번 20개 질문과 `expect_reach` 가 그 씨앗이다.
5. 자동 도달 판정의 한계가 다시 보였다(`[send]` 를 `Session.send` 로 못 봄). Phase 4 에서는 심볼 끝 이름 매칭 + 파일 일치로 바꾼다.
